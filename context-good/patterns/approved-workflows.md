# Personal data movement inside approved workflows

Some systems move personal data *by design*. The clearest case is SARBox: fulfilling a data subject access request means exporting one individual's personal data to that individual.

## Signals (all must hold)

- The export was generated by the SARBox export job (not manually assembled), **and**
- It sits in the SARBox outbox, **and**
- It is addressed to the *verified requester* of a referenced, open SAR case.

## Counterexamples — when this is NOT a false positive

- Export addressed to anyone other than the verified requester (the January 2026 near-miss: an export almost went to the wrong requester; verification of the addressee is exactly the check that matters).
- Data for *multiple* data subjects in a single SAR export.
- SAR-style exports found outside SARBox (someone hand-building a "SAR export" in email or personal storage).

## Scope note

"Approved workflow" is a narrow claim: it covers the documented behavior of a sanctioned system, verified case by case. There is no approved workflow for backing up corporate data to personal accounts (personal Gmail, Dropbox); no such exception process exists, whatever informal practice suggests.
